# gm_farm_builder

GameMaker: simple Farm Builder game, runtime resource management.

## Lessons example

With 1.5 hours per lesson.

1. Installation, room with background, ground.
2. Wheat seed, o_GameController, money variable, clicks (Left release).
3. Click to sow and to collect, money management, o_Money.
4. Carrot growth sprite, growth process, water and done indicators.
5. Shop, central prices.
